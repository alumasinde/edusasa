# Teachers — Phase 10

Phase 10 establishes the teacher domain inside the current EduSasa modular architecture.

## Scope

- Tenant-scoped teacher records
- Employee number, contact details and status
- Teacher-to-subject assignments
- Teacher-to-class assignments
- Permission-protected routes
- Integration point for Academic workflows

Teacher assignments are deliberately kept separate from timetable generation so the next Timetable phase can consume a clean teacher/class/subject relationship.

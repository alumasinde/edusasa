# Phase 3 — School Operations

Phase 3 transfers the existing SSMS school-operations implementation into EduSasa incrementally.

## Current
- Academic routing/foundation
- Student routing
- Student service lifecycle
- Tenant-scoped student repository
- Admission-number generation

## Next
- Guardian relationships
- Student medical, discipline, achievements and documents
- Student import/export
- Teacher/staff operations
- Teacher-subject assignment and import
- Attendance

The existing business logic is the source of truth. Refactoring is performed after the code is present and integrated, so working behavior is preserved while the UX and enterprise boundaries are improved.
